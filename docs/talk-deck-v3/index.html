## Dev loop: database changes

Every feature that touches the database:

1. Create a Neon branch for the feature
   neon checkout feat/addons --create
2. Pull the branch's environment variables
   neon env pull
3. Run the app against that branch
4. Make the migration and run it on the branch
5. Verify the feature end to end on the branch
6. Diff the schema: production vs. this branch
   neon branches schema-diff main feat/addons
7. Only then report the implementation as done
